# **Hello World!!!**

This is **SereneOS**. A soft neumorphic, browser-based desktop environment built with React, TypeScript, Vite, and Zustand. This is meant to be more than an OS simulation and more like an experience. A calming experience. It is still in its initial stages so the features are small but look forward to the new features!!!!!!!

## Features
- Window Management Engine: Drag-and-drop window positioning, 8-direction edge resizing, minimize, maximize, z-index focus handling, and double-click titlebar toggles.
- Persistent Virtual File System (VFS): LocalStorage-backed VFS with directory traversal, file/folder creation, deletion, and content updates.
- Desktop Shell & Taskbar: Windows-style taskbar with active window indicators, pinned launchers, top status bar, and live updating clock.
- Boot & Lock Sequence: Smooth booting visual sequence transitioning to an interactive passcode lock screen.

## Built-in Applications:
- File Explorer: Browse directories, traverse quick links, create folders, and open files.
- Text Editor: Full document editor integrated with the VFS for loading and saving files.
